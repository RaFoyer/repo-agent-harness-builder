# Repo Harness Bootstrap

## Workflow

1. Inspect the package archive safely.
2. Read `AGENT-HANDOFF.md` and `SETUP-CHECKPOINTS.md`.
3. Check local tools and repository access.
4. Install or use `repo-agent-harness-builder`.
5. Scaffold or clone the target repository.
6. Transfer authority to repo-native `AGENTS.md`, `AGENTS-TOC.md`, protocols, and CLI.

Do not copy secrets into chat. Do not treat this bootstrap skill as the repo's long-term source of truth.
