# Privacy And Secrets

Never print private document contents, credential values, tokens, keys, or long excerpts into chat.

Treat these as sensitive by default:

- identity documents
- legal records
- financial records
- medical records
- password manager exports
- private keys and certificates
- app data and hidden folders

Use file names and metadata when enough. Ask before content inspection.
