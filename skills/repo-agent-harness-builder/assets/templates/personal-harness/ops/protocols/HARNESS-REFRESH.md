# Harness Refresh

Refreshes are plan-based.

Before changing harness docs, scripts, or config:

1. Create a refresh plan.
2. Back up changed harness files.
3. Preserve receipts, inventories, plans, and quarantine.
4. Ask for approval.

Do not overwrite user rules without a backup.
